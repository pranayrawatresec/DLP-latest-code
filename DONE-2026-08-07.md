## 0. The decision we locked (network egress architecture)
For a **not-100%-air-gapped** defence endpoint that must "block every sensitive thing the agent
detects," we chose, and rejected, deliberately:
- **PRIMARY = read-taint.** Detect sensitivity at **read** (plaintext), taint the reading PID, block
  its egress. The only option that uses our content engine **and** works on **encrypted** egress
  **and** needs **no gateway** (works for distributed machines).
- **SAFETY NET = default-deny egress** (the user-mode WFP allow-list built 08-05).
- **REJECTED = TLS-intercept / ICAP proxy.** Cert-pinning defeats it exactly where it matters
  (AnyDesk, malware pin certs), and it needs infra we cannot assume. Optional later refinement only.

The block is **content-blind at the socket** — it keys on "this PID read the OPORD", not on the
bytes on the wire — so TLS/encryption is irrelevant. Clean PIDs return `CONTINUE` (not `PERMIT`), so
read-taint **composes with** the allow-list, never overrides it.

## 2. Kernel implementation built today  ✅ build-verified
Delivered via an orchestrated workflow (audit → 2 parallel coders → build+adversarial review, one
round, no fixes needed), then **independently re-verified from a clean build**.

### 2a. `dlp-minifilter/src/dlpflt.c` (+~1,200 lines)
- **Taint table** — `DlpTaintLookup` (the only ≤DISPATCH / WFP caller) / `DlpTaintAdd` /
  `DlpTaintRemove` / `DlpTaintResetAll`. Mirrors the hardened BadHash ring: `KSPIN_LOCK`, epoch
  stamp, ring eviction, PID-reuse `CreateTime` guard.
- **Sensfile cache** — `DlpSensFileLookup` / `DlpSensFileInsert` (cheap repeat-read fast path,
  stamped with the content policy epoch).
- **Async scan worker** — `DlpStartScanWorker` / `DlpStopScanWorker` / `DlpScanWorker` /
  `DlpScanEnqueue` / `DlpProcessScanJob` / `DlpFreeScanJob`. Runs at PASSIVE in the System process:
  `FltReadFile` the content → `DlpQueryVerdict(Reason=DLP_REASON_READ)` → on BLOCK `DlpTaintAdd(pid)`
  + seed sensfile/badhash. Bounded queue (drop = a miss = fail-safe); per-job scan rundown.
- **`DlpReadStreamContent`** — factored into the single in-kernel read path for both the write
  inspector and the read worker (this was the `C2129` build-breaker; now defined).
- **`DlpPostRead`** — 10-step gate: draining / kill-switch (`ReadTaintEnabled` + worker-ready) /
  `DlpShouldSkip` (PASSIVE + re-entrancy + self/System) / substantiality (≥512 B) / claim-once /
  sensfile fast-path / scope (removable+network = all, fixed = watch-prefix only) / bounded enqueue.
- **`DlpCreateProcessNotify`** — untaint a PID on process exit (PID-reuse safety).
- **DriverEntry / Unload wiring** — init taint state before `FltStartFiltering`; gated bring-up
  (worker → process-notify → `DlpWfpRegister`) after; WFP-register failure is **non-fatal** (FS/USB
  protection survives). Unload teardown in strict LLD §5.5 reverse order.

### 2b. `dlp-minifilter/src/wfpcallout.c` (NEW, 562 lines)
- `DlpWfpRegister` / `DlpWfpUnregister` + the `ALE_AUTH_CONNECT_V4/V6` classify callout.
- classifyFn never blocks; reads PID from `inMetaValues`; skips the guard PID + System; on a tainted
  PID applies the TEP matrix (`BLOCK_ALL` blocks everything; `BLOCK_NONLOCAL` permits
  RFC1918/loopback/link-local, blocks the rest) → `FWP_ACTION_BLOCK` + clears
  `FWPS_RIGHT_ACTION_WRITE` (hard veto), else `FWP_ACTION_CONTINUE`. **Byte-identical to
  `tcpreset.rs::tainted_egress_action`.**
- Idempotent, flag-guarded registration/rollback; teardown = filters → callouts → sublayer →
  provider → engine-close → `FwpsCalloutUnregisterById0` (bounded `STATUS_DEVICE_BUSY` retry) →
  `IoDeleteDevice`.

### 2c. `dlp-minifilter/build/build-driver.bat`
- Compiles `wfpcallout.c`, links `wfpcallout.obj` + `fwpkclnt.lib` + `ndis.lib` (WFP kernel imports).

## What is NOT done (honest boundary)
- 🧪 **Runtime unverified.** The `.sys` has not been loaded; the WFP block is **not yet proven on a
  VM**. This is the first runtime exercise of the callout — a clean compile is not a working driver.
  Driver Verifier (Pool Tracking + Force IRQL + Deadlock + DDI + WFP/NDIS) still owed, especially the
  **USB-yank / volume-dismount while a read scan is queued** teardown race (the one by-design risk the
  review flagged).
- 📄 **Single-hop taint only** = *reader → egress*. NOT built: **child-process taint inheritance** (a
  tainted process spawning a clean network tool), **derived-file propagation** (tainted process writes
  a file another process reads), **clipboard/IPC propagation**. Full multi-hop data lineage is a
  separate design pass.
- Prior limits stand: screen-view analog hole; kernel-privileged adversary; encrypted exfil to an
  **allowed** destination. Highest assurance = this DLP **+** EDR + least-privilege + (top end) air-gap.
