Configuration Catalogue

DLP Settings Reference

Every setting in the endpoint DLP product — read from the code (agent config, driver registry knobs, and the console-managed lists) so nothing is missed when the console UI is built. Each row shows what it does, its values, its default (bold), and where it lives today. The goal: every one of these becomes a control the admin operates from the console — no command line.

Console
Managed centrally in the console today, synced to agents over mTLS.
Endpoint policy
In each agent's agent.toml today — should move to the console.
Driver knob
Kernel registry value — the agent should set it from console policy.
Install / auto
Set at install or handled automatically; not an operator toggle.

Reading the "Where" column: anything marked Endpoint policy or Driver knob is configured per-machine today (the CLI/registry steps used during testing). The target design moves all of them behind Console controls that the agent applies to each endpoint automatically.
