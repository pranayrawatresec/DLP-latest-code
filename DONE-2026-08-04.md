## 1. Content Detection Engine (server + agent)

### Server (`dlp-management-server/`)
- ✅ **IDM fingerprinting** — `lib/fingerprint.js`: NFKC normalize → k=8 word shingles → FNV-1a 64
  → winnowing (w=8). Golden test-vector fixture is the cross-language contract. (14 tests)
- ✅ **Text extraction** — `lib/extractText.js`: txt/md/csv, docx/xlsx/pptx, PDF text layer,
  recursive zips; `UnreadableError` reason codes for encrypted/unsupported. (21 tests)
- ✅ **Encrypted blob store** — `lib/blobStore.js`: AES-256-GCM, per-blob wrapped keys under
  `DLP_BLOB_MASTER_KEY`, tamper-detected. (15 tests)
- ✅ **Protected Content Repository** — migration `002_protected_documents.sql`
  (`protected_collections`, `protected_documents`, `document_versions`, `document_fingerprints`,
  `processing_jobs`); `routes/protected.js` (two-gate auth, `protect:write`/`protect:read`, audited);
  async registration + `bin/fingerprint-worker.js` (Postgres `SKIP LOCKED` queue). (13 e2e tests)
- ✅ **EDM authoring** — migration `003_edm_sources.sql`; `lib/edm.js` (typed normalization
  text/id/number/date, salted SHA-256 truncated to 64-bit); CSV ingest worker job that **deletes the
  plaintext blob after hashing**. (17 tests)
- ✅ **Signed index bundle** — migration `004_index_bundles.sql`; `lib/indexBundle.js` +
  `docs/index-bundle-format.md` (magic, header, Bloom filter, sorted IDM/EDM sections, RSA-SHA256
  CA signature); compile job; distribution via check-in + `GET /agent/index` over mTLS. (13 tests)
- ✅ **Incidents** — `lib/incidents.js`, `routes/incidents.js`: agent verdict → server resolution
  (matched hashes → page/seq ranges + title) → reviewer view.
- ✅ **Index status** — `GET /api/protected/index`: last compiled version + pending-since count
  (drives the console "compile needed" banner).

### Agent (`dlp-agent/`, Rust)
- ✅ **`detect/` module** — normalize/shingle/winnow **bit-identical to the server** (gated by
  `tests/golden_vectors.rs`), extraction, `bundle.rs` (loader + CA signature verify), `edm.rs`
  (proximity matcher), `verdict.rs` (containment/coverage scoring). (golden 6 + extract 21 +
  bundle_loader 7 tests)
- ✅ **`scan` CLI** — `scan --bundle --file [--json] [--report --channel]`; `index-update`.

### End-to-end (✅ verified)
Register a .docx + personnel CSV over HTTP → workers → compile signed bundle → **real Rust binary**
matches a mutated document (containment 1.0), fires EDM on the right row, stays clean on innocent
input, fails secure on random bytes → incident round-trips to a reviewer with page ranges.
(`scripts/detection-e2e.js`, 7 checks.) Server suites 151 pass; agent suites verified independently.

## 4. Kernel Filesystem Minifilter (`dlp-minifilter/`)  — true blocking

Production DLP minifilter modeled on Microsoft's `scanner` sample: intercepts writes to **removable
volumes only**, sends the path to the user-mode agent over a communication port, blocks/quarantines
files containing protected content.
- `src/dlpflt.c` (registration, removable-only `InstanceSetup`, CREATE/WRITE/CLEANUP/SET_INFO
  callbacks, stream contexts, self-skip by service PID), `src/comms.c` (`\DlpFltPort`, FailMode),
  `src/dlpflt.h` (shared `DLP_SCAN_REQUEST/REPLY`).
- `dlpflt.inf` (FSFilter Content Screener, altitude 265000 dev), build/analyze scripts,
  test-cert/sign/install/uninstall scripts, `README.md`.
- `dlp-agent/src/kguard/` + `usb-guard` subcommand — connects to the port, runs `detect::verdict()`,
  replies allow/block, raises incidents.
- ✅ **Verified (compile-time only):** builds to a real native kernel driver `dlpflt.sys` (17,408
  bytes, `dumpbin` subsystem = Native) under `/W4 /WX` clean; `cl /analyze` clean on our source; Rust
  `usb-guard` builds clean, 87 agent tests pass; **no file content crosses the port** (path+metadata
  only, grep-confirmed).
- 🧪 **Manual-only (runtime — NOT verified, kernel bug = BSOD, test on spare/VM only):** loading
  without bugcheck, correct blocking/quarantine, self-skip preventing deadlock, FailMode end-to-end,
  real USB copy. Steps in `dlp-minifilter/README.md`.
- ⚠️ **Blocking model is v1** — scan-on-close then delete-if-sensitive (file briefly exists on media
  before removal); zero-residue hold-before-commit is v2.
- ⚠️ **Not yet load-ready** — INF needs `stampinf` `DriverVer` + `.cat` (inf2cat) + test-signing.
- 📄 Spec: `dlp-minifilter/SPEC.md`.
