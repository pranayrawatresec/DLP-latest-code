One Architectural Improvement I'd Recommend

The PDF says:

The management server runs its own internal CA.

For a production-grade system, I would refine this slightly:

                Offline Root CA
                      │
                      │ signs
                      ▼
           Intermediate CA
      (on the Management Server)
                      │
         ┌────────────┼────────────┐
         ▼            ▼            ▼
      Agent 1      Agent 2      Agent 3

Why?

The Root CA stays offline and is used only to sign the Intermediate CA.
The Management Server uses the Intermediate CA to issue agent certificates.
If the Management Server is compromised, you revoke the Intermediate CA and issue a new one. The offline Root CA remains trusted.

This is the same layered PKI model used by enterprises and public certificate authorities.
